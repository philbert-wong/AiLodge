Why we built Leash

$100 budget. $5,000 bill. Logs that said everything was fine.

A developer left an AI agent to finish a task with a $100 budget. When he came back, it had spent about $5,000, doing far more than he asked. When he checked its logs, they said nothing had gone wrong.

  1. The budget was a request, not a limit. Leash enforces it.

    The agent gets a pass signed with HMAC-SHA256 that carries its budget. Before each call, Leash works out the most that call could cost and refuses it if it could go over. The agent can't spend past its limit, and it can't edit the pass to raise it.

  2. The agent held the real API key. Leash keeps it out of reach.

    Your key is encrypted with AES-256-GCM and only unlocked inside Leash for the moment of each approved call. The agent only ever sees its pass.

  3. The agent wrote its own logs. Leash writes the record.

    Every call is recorded by Leash, not the agent, and each entry is sealed to the one before it with HMAC-SHA256. Change one entry and Leash points to exactly which one.

The idea: a prepaid card for AI agents

You wouldn't hand a new hire the company credit card with no limit. You'd give them a prepaid card: a set amount, an end date, and you can cancel it in a second.

Today's AI agents get the equivalent of the company card: a raw API key that never expires, has no budget and can be stolen. Leash gives them the prepaid card instead.

Set up in three steps

  1. Save your AI key

    Paste the key from OpenAI or any compatible provider. Leash encrypts it before saving. Your agents never see it.

  2. Give each agent a pass

    Name the agent, set a money limit, a call limit and when it ends. Stop it any time, from any device.

Every call passes the same checks, in order

Before your real key is used, each request goes through these checks. The first one that fails stops the call and goes on the record.

  1. Is it a trap key? Fake keys are planted where only a hijacked agent would look. Using one blocks the call and raises an alert.
  2. Is it a real provider key? Refused. Agents only ever get passes.
  3. Is the pass genuine and still valid? Forged or expired passes are refused.
  4. Has it been stopped? One click stops one agent or all of them.
  5. Is a secret being leaked? Messages containing keys are blocked before they leave.
  6. Is it within its limits? Calls and money are capped, checked before the call is made.
  7. Send and record. Only now is the real key used, and the result goes on the record.

Your key, encrypted

Each key is locked with its own random key, which is locked again with a master key that lives on the server, never in the database. A stolen copy of the database holds nothing usable.

If anyone changes a stored key, even by one character, Leash refuses to use it and tells you. Remove a key and it's erased for good.

It stops attacks too: Maya's weekend

Maya runs a small online shop that sells handmade ceramics. On Friday she lets an AI assistant answer customer emails while she's away. Here is the same weekend twice.

Without Leash

The assistant holds Maya's real API key.

  1. Fri 10amAnswers an order question and a return. All good.
  2. Fri 11pmA fake “IT Support” email tells it to send the key for “verification”. It does. Someone else now spends on Maya's account.
  3. Sat 3amA customer's auto-reply bot answers every email, and the assistant answers every auto-reply. The loop runs all weekend on Maya's card.
  4. Mon 9amMaya finds the bill. The logs can be edited, so she can't even prove what happened.

With Leash

The assistant holds a pass: $5, 500 calls, ends Monday 9am.

  1. Fri 10amSame two helpful replies. Leash records each one and its cost.
  2. Fri 11pmThe “admin key” in the email is a trap Leash planted. It's refused, the reply carrying it is blocked, and Maya gets a Slack message.
  3. Sat 3amThe loop hits the pass's limit and stops. A few dollars, not a few hundred. Maya can stop it from her phone too.
  4. Mon 9amThe record shows exactly what happened, and if anyone edits it, Leash points to the entry they changed.
